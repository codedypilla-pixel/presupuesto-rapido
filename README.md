# Presupuesto Rápido

Generador de presupuestos en PDF para autónomos y pequeños negocios. Gratis, sin registro y sin servidor.

**Úsalo aquí:** https://codedypilla-pixel.github.io/presupuesto-rapido/

- Rellenas tus datos, los del cliente y las líneas del presupuesto, y pulsas **Imprimir / PDF**.
- Calcula descuento, base imponible, IVA y total.
- Admite logo, notas y condiciones, fecha de validez y varias monedas.
- Tus datos se guardan solo en tu navegador (`localStorage`); no se envían a ningún sitio.
- Puedes guardar y abrir copias en un archivo `.json`.
- Interfaz en español e inglés.

Es un único archivo `index.html` sin dependencias: puedes descargarlo y abrirlo sin conexión.

> Genera presupuestos, no facturas. No es un sistema de facturación ni sustituye a uno.
